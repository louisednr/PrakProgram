Explanation for the difference between traditional and modern forms of operator+
Old input: (const vec& a, const vec& b) is different from the modern input: (vec a, const vec& b)
The old had to define a new vector 'r' manually: vec r = a;
This adds an extra line (higher chance for typos).
 Instead, can simply edit the copy of the first vector.
