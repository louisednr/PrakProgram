# Homework: "Recursive Adaptive Integration"

This project implements an adaptive **open quadrature integrator** featuring a **Clenshaw–Curtis variable transformation** to resolve endpoint singularities and evaluate convergent infinite-limit integrals.

## Prerequisites
- **Compiler**: A C++ compiler supporting **C++23**.
- **Tools**: `make` for automation, python3 (with scipy and matplotlib), and gnuplot for generating SVG visualizations.
